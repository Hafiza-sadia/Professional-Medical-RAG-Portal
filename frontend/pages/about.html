🏥 About MediQ

Professional Medical RAG Portal

MediQ is an enterprise-grade AI system combining Retrieval-Augmented Generation, FAISS vector search, and Groq Llama 3 to deliver evidence-grounded clinical answers from your own uploaded medical documents.

⚡ FastAPI Backend 🧠 FAISS Vector DB 🤖 Groq Llama 3 📄 LangChain RAG 🔒 Local Storage
🔧 Technology Stack
⚡

FastAPI + Uvicorn

High-performance async Python REST API serving both the frontend HTML pages and all JSON endpoints for upload, query, and vectorstore management.

🧠

FAISS Vector DB

Facebook AI Similarity Search (FAISS) provides millisecond-speed approximate nearest-neighbor retrieval over millions of document embeddings locally.

🔤

Sentence Transformers

all-MiniLM-L6-v2 generates dense 384-dimensional semantic embeddings for document chunks, enabling context-aware retrieval far beyond keyword search.

🤖

Groq Llama 3

Llama 3 synthesizes retrieved context into clinical-grade answers using structured prompt engineering with citation grounding, served at ultra-low latency.

🔗

LangChain Framework

Orchestrates the RAG pipeline: document loading, text splitting, embedding, vector storage, context retrieval, and LLM chaining with prompt templates.

📄

PyPDF2 Extraction

Robust multi-page PDF text extraction with UTF-8 normalization for handling complex medical documents, research papers, and clinical guidelines.
