# MediQ AI Portal

An AI-powered Medical RAG Chatbot built with:

- Python
- FastAPI
- LangChain
- FAISS
- Groq
- Llama 3.3 70B
- Docker

## Features

- PDF Upload
- Multi-document Support
- Medical Question Answering
- Source Citations
- Session History
- AI Settings
- Knowledge Base Management

## Run Locally

```bash
pip install -r requirements.txt
python run.py
```

## Deployment

This application is deployed on Hugging Face Spaces using Docker.
